# Lament for the Fallen South — Background Image Prompts

These prompts are for background generation only. Generate clean images without titles, subtitles, UI, logos, watermarks, captions, calligraphy, or readable writing. Add all game text in Godot afterward.

## Shared visual direction

Use this visual direction with every prompt:

"horizontal 16:9 game background, restrained monochrome Chinese ink wash environment, aged rice paper texture, charcoal black and soft gray values, subtle indigo-gray atmosphere, sparse muted vermilion accents only when specified, poetic negative space, layered brushwork, cinematic composition, quiet melancholy, elegant 2D visual novel background, no readable marks"

## Shared negative prompt

"text, letters, Chinese characters, Japanese characters, Korean characters, calligraphy, inscriptions, subtitles, captions, title, logo, watermark, signature, stamp, seal script, readable writing, pseudo-text, random symbols, UI, buttons, frame, border, speech bubble, comic panel, photorealism, glossy 3D render, oversaturated colors, modern objects, modern buildings, cars, electricity wires"

## Suggested image-to-image consistency note

For every generation, keep the same camera language, paper texture, gray scale, brush density, horizon softness, and restrained color palette. Use the opening cutscene or study image as a style reference for later memory backgrounds. Generate the environment and the manga-style character separately when possible, then layer them in Godot so the selected memory object can be colorized independently.

## Suggested restrained color palette

- Ink black: #191817
- Paper gray: #D8D2C6
- Cold water blue-gray: #667C83
- Old vermilion: #8B4036
- Aged ochre: #A48A5A

Use color sparingly. A selected object should be the only strongly colored element in a memory scene.
