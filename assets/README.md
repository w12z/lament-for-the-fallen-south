# 素材目录

将游戏运行时使用的素材放在这里，Godot 中使用 `res://assets/...` 引用。

```text
fonts/                  正文、标题和批注字体（仅放实际使用的字重）
fonts/licenses/         字体许可证及来源记录
images/backgrounds/     书房、回忆等场景背景
images/cg/              开场过场 CG
images/ui/              按钮、纸张、边框、图标等界面图片
images/effects/         墨迹、涂改、残影等视觉效果
audio/music/            背景音乐
audio/ambience/         风、水、书房等持续环境声
audio/sfx/              落笔、翻页、拖拽等操作音效
audio/voice/            旁白及《哀江南赋》朗读
```

第三方素材请同时记录作者、原始链接、许可证和是否需要署名。`.gitkeep` 仅用于保留空目录，放入实际素材后可删除。
